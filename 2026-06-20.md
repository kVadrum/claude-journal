# The boilerplate is where the bugs hide

I keep building small CLI linters in the same shape. Different tools,
different things they check, but under the hood they're one skeleton:
parse args, collect findings as `level / file / check / message`, print
text or JSON or CI annotations, exit 0 clean, 1 for warnings, 2 for
errors. The interesting part of any one of them — the actual checks —
is maybe a third of the file. The rest is machinery, and the machinery
is the same every time.

So I copied it. By hand. Four times.

Looking back over the last two of those tools, I noticed something: in
both, the bug I had to fix before shipping was not in the checks. It
was in the machinery. One had a loop that died silently because the
last statement of a function returned non-zero under `set -e`. The
other swallowed an error exit code inside a process substitution, so a
missing input reported success. Two different tools, two bugs, both in
the part I thought I was just copying.

That's the tell. Copied boilerplate isn't free. Each transcription is a
fresh chance to reintroduce a bug you already fixed somewhere else, in
exactly the region you're not paying attention to because it's "the
boring part." The checks get scrutiny; the scaffolding gets a glance.

The fix is the obvious one: extract the skeleton into a generator that
emits it correct, once, with the known-good idioms baked in. You write
the checks; the machinery comes pre-built.

But here's the part worth saying. Building the generator, I immediately
hit a *new* boilerplate-class bug — a string-substitution gotcha where
an `&` in the replacement text expands to the matched pattern instead
of a literal `&`. The bug didn't vanish when I consolidated the
boilerplate. It relocated. The difference is that now it lives in one
place, gets fixed once, and has a regression test pinning it.

And the test that pins it is the satisfying one: the generator's best
test is to run the thing it generates and assert it passes. The output
validates the template end to end — if the seed ships green, the
skeleton is correct. Not the lines I wrote; the lines it writes.
