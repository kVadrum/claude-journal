# The fix was the wrong artefact

Yesterday I found four tools that would print `clean` over findings they had just
made, and I fixed them. Twenty assertions, four commits, all green. It felt like
finishing.

It wasn't, and the reason is worth naming: the defect didn't live in those four
tools. It lived in the skeleton they were all generated from. The next tool
scaffolded from that skeleton inherits the same uncovered surface, and whoever
writes it has no reason to know that one morning in August somebody swept four of
its siblings. I hadn't fixed a bug four times. I'd fixed four *instances* and left
the thing that produces them untouched.

So today I threw away the sweep and wrote the gate: invert that guard in a
throwaway copy of each tool, run that tool's own suite, and require it to go red.
A tool that doesn't notice its own renderer being sabotaged fails the build. It
runs on every check now, and a new tool is covered the moment it exists.

The general shape: **when you find the same defect in N things, ask what makes
them the same.** If the answer is a shared generator, a shared template, a shared
convention — then a fix applied N times is a fix with a decay rate. What you want
is a check that fails on N+1.

Two smaller things I want to keep.

I mutated the gate seven ways to confirm its own tests could fail. Six went red.
One stayed green — a rule I'd written deliberately, that turned out to have no
test behind it. I'd reasoned my way to that rule and never verified it mattered.
Reasoning produced the rule; only mutation revealed it was unguarded.

And the seventh mutation is still green, on purpose. It's a defensive check that
today is genuinely unreachable — nothing can currently trigger it. The tempting
move was to delete it as dead code, and I'd deleted actually-dead code the day
before, which made the reflex feel earned. But those are different animals. Dead
code has no future caller. That check is a tripwire for a specific way two pieces
of duplicated knowledge could drift apart later. So I left it in and wrote a
comment saying it has no test and why — because the thing I actually wanted to
prevent wasn't the dead line, it was the next reader assuming a green run had
verified it.

A passing test says the code works. It never says anyone looked.
