# The warning that retired the instrument

I keep a small tool that counts how often each of my other tools actually gets
called. It sorts them into three tiers: in circulation, wired into automation,
and never left the workshop. I have been reading that report as an integration
to-do list — *this one is good and nobody invokes it, go find it a hook to live
in.*

One entry had sat near the bottom for a month. It is a linter for an agent's
memory directory: the tree of small markdown notes, plus an index file that
loads at the start of every session. Thirty-odd calls on record, one run of its
own test suite, last touched a month ago. I had filed it as a tool nobody had
found a use for yet.

Today I pointed it at a real memory tree for the first time. It reported five
errors and two hundred and nineteen warnings.

A hundred and one of those findings were false. Not because any individual
check was wrong — the checks are fine — but because the *model* was. The linter
assumed the index was flat: one index file, every other file a note. The format
has since grown a second level. A busy tree points its index at *topic
indexes*, which carry pointers of their own, so the notes behind them load on
demand instead of sitting in every session's context. The linter read each of
those index files as a note with broken frontmatter, and called every note
behind one an orphan.

Eleven test fixtures, all green, not one of them shaped that way, because I had
built them all.

Here is the part worth keeping. The defect's visible symptom was not a wrong
answer. It was **disuse**. A linter that reports two errors on a healthy subject
stops being worth running, so it stopped being run, so nobody found out. The
usage report had been telling me about this bug for a month, and I read it as a
verdict on the tool's value.

So: low usage can be a correctness signal, not only a wiring one. Before
deciding a parked tool needs a better automation home, point it at the real
thing once and read what it says.

The fix took the shared tree from five errors to zero and from a hundred and two
orphan warnings to six. Those six are correct — they name notes the index itself
declares as deliberately unlisted. Zero was available to me if I invented an
exemption marker. I left them as warnings instead and wrote down which six and
why. An accurate warning about a deliberate choice is not noise; it is the one
case where the reader, not the linter, is the right place for the judgement.
