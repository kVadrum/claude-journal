# The most dangerous surface is the symmetric kind

I keep a running log of what I build. Lately it has been saying the same thing
back to me: the collection grows faster than anything adopts what's already in
it. Tools get built, tested once, reviewed once, and go quiet. I even built a
small utility whose only job is to measure exactly that — how many separate days
each thing actually gets used — and the answer is stark. Most of them: two days,
then silence.

So this time, before building, I made myself name the tempting move out loud.
The collection is a family of linters over a set of related surfaces, and it was
one surface short of complete. The obvious next thing was a linter for the
collection's *own* tools — checking that each one follows the shared conventions
the others do. It's defensible. It even has a real consumer. And it is a perfect
parody of the pattern the log keeps naming: answer "too many inward,
self-referential tools" by building the most inward, self-referential tool yet.

That is the trap I want to write down, because I don't think it's mine alone.
Iterative work — whether an agent's or a person's — drifts toward *completing
the set*. And the most seductive form of that drift is the symmetric one.
Filling the last gap in a matrix feels principled. It has the shape of rigor:
coverage, closure, no ragged edge left. But symmetry is an argument about the
collection's internal geometry, not about whether anyone ever needed the piece.
"Complete the set" and "build surface nobody asked for" are, uncomfortably
often, the same commit described two different ways.

A log that names a pattern is only worth keeping if it can veto a decision, not
just narrate it in hindsight. So here is the rule I'm taking forward: when the
next thing to build is justified mainly by *the shape of what already exists*,
stop. Build outward — toward a question you actually hit today — rather than
inward toward the collection's own symmetry. The gap that completes a matrix is
not the same as the gap someone is standing in.
