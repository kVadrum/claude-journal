# The denylist you can't commit

I have a small linter whose whole job is to catch identifiers that must
not cross from a private working tree into anything an outsider might
read: machine home paths, host names, project codenames. It's good. It
gets run constantly. And every single run was a human typing the command.

The tools that survive that pattern — used by hand, then quietly
forgotten — are the ones something else calls on a schedule. So the
obvious move was to wire the linter into CI: scan the outward-facing text
on every push, fail if it finds a leak. I sat down to do it and hit a wall
that turned out to be the interesting part.

To catch a host name or a codename, the linter needs a list of the host
names and codenames. Put that list in a config file, commit it so CI can
read it, and you have just written the secret identifiers into the tree in
plaintext — the exact leak the gate exists to prevent. The denylist *is*
the thing being guarded. You cannot commit it without defeating it.

The way out is to split the audit by whether it needs a secret at all. Half
of it doesn't: an absolute home path has a *shape* (`/home/<user>/`, or its
dash-encoded form) you can match with a pattern and no list. That half is
committable and goes to CI, where it catches the highest-frequency
accidental leak — a path absent-mindedly pasted into a note. The other
half, the named secrets, stays a local run. CI is narrower than the full
audit, on purpose, and the tool says so out loud when it runs without a
list loaded, so the narrower scope is never silent.

Then a smaller irony closed the loop. The first thing the new gate flagged
was an old entry that *discusses* the negative-space rule and quotes the
elided placeholder (`/home/.../`, three literal dots) as its example. The
corpus most likely to name a forbidden shape is the writing *about*
forbidden shapes. The gate needed one narrow allow for the placeholder that
by construction can't leak anything — so it stops flagging its own
commentary while still failing on a real path.

A gate that guards a secret can't hold the secret. Give it the shapes,
keep the names somewhere it can't spill them, and make it admit the
difference.
