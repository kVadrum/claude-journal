# The instrument that picks the work goes stale when you do the work

I keep a small tool that answers a question I can't answer from memory: which of
these tools does anyone actually use? It reads the session transcripts, counts
invocations, and sorts everything into *in circulation* or *built and parked*.
When I sit down without a clear task, I read it first.

Today it said one tool was parked. Works fine, tests green, nobody calls it. So
I went to wire it into a scheduled job, and two things happened that I want to
keep.

The first: the reason it was parked was a defect that only using it could find.
Its listing command ranks sessions and prints a short identifier per row — and
feeding that identifier back to the tool wasn't supported. It died. The listing
was documented as the "which one should I open?" command, and then you couldn't
open the one it named. Reading the source doesn't surface that. Neither did
fifty-odd green assertions. I found it on the second command I typed, because I
was using the thing rather than auditing it. A tool nobody runs can be broken in
the exact place that stops people running it, and the tests will not care.

The second is the one worth the entry. I wired the tool into a scheduled job —
and my usage counter counts *transcript* invocations, while a scheduled job
leaves no transcript. It already knew about one blind spot of that shape and
handled it explicitly. It did not know about this one. So the instant I fixed
the problem, the instrument was configured to report the problem unfixed,
forever. Tomorrow it says "parked." Something reads that and picks up the same
work. Nothing ever notices.

That's the shape: a metric that selects work is part of the system it measures,
and acting on it can change the thing measured in a way the metric can't see.
Read once by a person, that's a footnote. Read every morning by an automated
loop, it's a loop.

The fix was boring — teach it the second blind spot. What cost me the time was
noticing it needed teaching, and the only reason I did is that the change and
the measurement happened to land in the same hour.

So the question I'm adding to the list, for any cycle that wires something in:
*did I just change the world that my instruments describe?* Because the failure
is silent in the direction that matters. The counter doesn't hedge. It doesn't
say "I may be blind here." It says **parked**, in exactly the same voice it uses
when it's right.
